# Transaction Risk ML

Учебное исследование классификации риска транзакций на Python, pandas и scikit-learn. Главный вопрос: что происходит с качеством модели, когда из признаков исключаются готовая оценка риска и тип операции?

## Происхождение

Проект вырос из научно-исследовательского семинара Финансового университета. Авторы исходной командной работы: Владислав Филатов и Фёдор Ключарев. За исходную программную реализацию отвечал Владислав. Начальная версия сохранена в `legacy/original_ml.py`.

В версии для портфолио появились единые условия сравнения, baseline, проверка входных данных, экспорт модели и тесты. Доработка выполнена с помощью ИИ. Результаты в `reports/` получены реальным локальным запуском.

## Эксперимент

Одна стратифицированная выборка 80/20, `random_state=42`. В трёх основных вариантах используется один Random Forest с одинаковыми параметрами: 100 деревьев, `min_samples_leaf=2`. Меняется только набор признаков.

| Вариант | Что поступает в модель |
|---|---|
| `dummy` | Всегда предсказывает самый частый класс |
| `with_score` | Поведенческие поля, `transaction_type`, `risk_score` |
| `without_score` | Те же поля, но без `risk_score` |
| `behavior_only` | Без `risk_score` и `transaction_type` |

Идентификаторы адресов, timestamp и целевая метка не используются как признаки. Преобразования обучаются внутри Pipeline только на тренировочной выборке. Категории кодируются OneHotEncoder, неизвестные значения допускаются.

Результаты и интерпретация: [RESULTS.md](RESULTS.md). Полные отчёты и матрицы ошибок: [reports/metrics.json](reports/metrics.json).

## Данные

[Metaverse Financial Transactions Dataset на Kaggle](https://www.kaggle.com/datasets/faizaniftikharjanjua/metaverse-financial-transactions-dataset): 78 600 строк, 14 столбцов, метка `anomaly` с классами `low_risk`, `moderate_risk`, `high_risk`.

Это учебный набор о моделируемой среде. Метки не доказывают наличие реального мошенничества. CSV не включён в репозиторий: скачайте его у автора набора и проверьте условия использования на странице источника. Подробности: [DATA.md](DATA.md).

## Запуск

Проверено с Python 3.12. Выполняйте команды из папки репозитория.

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements-dev.txt
.venv\Scripts\python train.py --data data/metaverse_transactions_dataset.csv
.venv\Scripts\python -m pytest -q
```

На Linux/macOS замените `.venv\Scripts\python` на `.venv/bin/python`.

Результат обучения: `artifacts/metrics.json` и `artifacts/model.joblib`. Модель для API — заранее выбранный вариант `behavior_only`. Мы не выбираем победителя по тестовой выборке. Артефакт содержит обученный Pipeline, схему признаков и версию scikit-learn.

Для быстрого пробного запуска можно указать `--trees 20`; полученные метрики будут отличаться от опубликованного запуска со 100 деревьями.

## Структура

- `risk_model.py` — признаки, валидация и сборка Pipeline.
- `train.py` — одинаковый split для всех вариантов, обучение, метрики и экспорт.
- `tests/` — проверка исключения целевых подсказок, неизвестных категорий и некорректных данных.
- `legacy/` — исходная учебная версия, для истории проекта.
- `EXPLAIN.md` — разбор решений и вопросы для самостоятельной проверки понимания.

## Ограничения

Один случайный split не проверяет перенос на другой период, источник или организацию. Даже `behavior_only` может использовать зависимости генератора данных. Вероятности не калиброваны. Прототип не предназначен для принятия финансовых решений или блокировки реальных операций.
